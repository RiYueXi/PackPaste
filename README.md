# PackPaste · 打包复制 / 解包粘贴

Windows 11 x64 的文件右键工具，使用 C#、.NET 9 和 Windows Forms。生成 tar.gz 文件包，支持多选文件及文件夹、中文路径、空目录、进度、取消和同名冲突处理。

## 1.0.1 修复

- 修复文件夹和桌面空白处缺少“解包粘贴”：不再为无选择项的背景菜单设置 `MultiSelectModel=Single`。覆盖安装时删除旧版遗留值。
- 打包、粘贴成功且没有清理警告时，进度窗口在 350 毫秒后自动关闭。失败、取消和清理异常仍保留结果，避免丢失重试信息。
- 从 1.0.0 升级：关闭任务窗口，运行新版安装包覆盖安装，无需先卸载。

## 安装与使用

1. 从本仓库的 Releases 下载 `PackPaste-1.0.1-win-x64-Setup.exe`（或自行构建后在 `dist` 中获取），双击安装程序，允许管理员权限，然后点击“安装”。安装到 `%ProgramFiles%\PackPaste`，右键菜单对所有用户可用。
2. 在资源管理器中选中文件或文件夹，右键 → **显示更多选项 → 打包复制**。
3. 打包完成后，在目标文件夹空白处右键 → **显示更多选项 → 解包粘贴**。也支持对目标文件夹、磁盘和桌面执行解包粘贴。
4. 同名文件可选择覆盖、跳过或重命名，并可应用到后续所有冲突。同名文件夹合并，内部文件逐项处理冲突。
5. 成功后清理两端临时文件包；剪贴板仍指向本次文件包时清除该引用。本次包不能再次粘贴。

需要预先安装 **.NET 9 Desktop Runtime x64**（`Microsoft.WindowsDesktop.App 9.x`）；安装包不携带或自动下载运行环境。仅有 ASP.NET Core Runtime 或普通 .NET Runtime 不足以运行界面。可用 `dotnet --list-runtimes` 检查。

安装器是约 270 KB 的单文件 EXE，未做商业代码签名。安装器请求管理员权限，实际复制粘贴程序以当前用户普通权限运行。用户不能访问的目录会显示错误。

安装后立即可用，不需要服务、自启动项或重启。右键菜单持久注册，重启后仍可使用；处理程序按需启动，COM 接收进程无活动窗口后约 45 秒退出。

## 文件与取消行为

- tar.gz 是打包压缩，不做密码加密。默认使用快速压缩，主要面向本机传输。
- 粘贴先在目标目录下创建 `.PackPaste-<随机编号>`，复制压缩包、校验 SHA-256、完整解压，然后放置目标文件。避免解压中途留下半个目标文件。
- 取消或失败保留源文件包，可重新“解包粘贴”。目标临时目录也会保留，界面显示其位置，可重试后自行删除旧目录。
- 放置阶段取消，已经放置的完整文件不会回滚；已经覆盖的旧文件不能通过取消恢复。
- 选择“跳过”视为该项目已处理，成功后仍删除压缩包。原始文件始终保留。
- 本工具一次执行一个任务。重新打包成功时，如果旧剪贴板也指向本工具的包，会尝试清理旧包。
- 用户缓存位于 `%LOCALAPPDATA%\PackPaste\Transfers`。崩溃或剪贴板被其他程序覆盖后遗留的包，可在没有任务运行时手动清理。
- 目标磁盘需要同时容纳压缩包及解压内容；源缓存磁盘也需要压缩包空间。文件列表保存在内存，文件内容按块流式处理。
- 不支持符号链接、目录联接、其他重解析点和直接打包整个磁盘。归档保留内容、文件夹层次和文件修改时间；不复制 NTFS ACL、备用数据流等完整 NTFS 元数据。
- 只接受当前用户通过本工具复制的文件包。普通系统“复制 / 粘贴”和 Ctrl+C / Ctrl+V 保持系统行为；请使用独立右键命令完成整个流程。

## 卸载与更新

Windows 设置 → 应用 → 安装的应用 → **打包复制 / 解包粘贴** → 卸载。

卸载会删除程序和机器级右键注册项，保留原始文件及用户临时缓存。更新可重新运行安装包。若提示程序占用，请关闭任务窗口并等待约 45 秒后重试。

## 构建与验证

在 Windows x64 上安装 .NET 9 SDK 后运行：

```powershell
.\build.ps1
.\test.ps1
```

首次构建需要从 NuGet 下载微软的单文件发布构建组件；这些是构建依赖，不是随安装包发布的运行环境。`build.ps1` 生成主程序、嵌入安装载荷，发布依赖本机运行环境的单文件安装器。NuGet 缓存和构建配置目录均位于工作区。

`PackPaste.Tests` 是无第三方测试框架的自动验证程序，覆盖内容一致性、多选与重复路径、空文件夹、同名策略、取消、恶意路径、损坏包、Shell 文件列表、跨进程 COM 激活、安装载荷和界面渲染。测试不修改真实剪贴板，不注册右键菜单，不执行机器级安装。完整的管理员安装、真实资源管理器菜单点击及卸载，需要安装后人工验收。

1.0.1 另通过一次真实 Windows Shell 菜单回归验证：独立临时背景菜单设置 `Single` 时隐藏，调用生产修复代码清除此值后显示；测试项随后删除。诊断命令 `PackPaste.Tests.exe --menus <目录>` 仅读取 Windows 实际生成的背景菜单；`--menu-regression <目录>` 会短暂创建并清理独立的当前用户测试菜单项。

可使用 `PackPaste.sln` 打开解决方案。生成安装包时请先执行 `build.ps1`，它会按顺序构建主程序，再生成安装器内嵌的文件包；普通的解决方案构建不能替代这个步骤。

项目结构：

- `PackPaste`：Windows Forms 界面、流式 tar.gz 引擎、Shell IDropTarget COM 本地服务器。
- `PackPaste.Setup`：所有用户安装器、卸载器和注册项管理。
- `PackPaste.Tests`：自动验证与界面截图。
- `dist`：最终安装包及 SHA-256 校验文件。

机器级注册位置：`HKLM\SOFTWARE\Classes` 下的专用 `PackPaste.Copy` / `PackPaste.Paste` 菜单项，CLSID `{91AE144F-295F-4807-93C1-F47597495B52}`，及 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\PackPaste`。不覆盖系统原有复制粘贴命令。
